# Doc 145: Revenue Intelligence → Conversion Feedback Loop
**Version:** 1.0 | **Last Updated:** April 5, 2026 | **Series:** 140 (System Bridge)

---

## PURPOSE

This system ensures:
- Revenue signals control decisions
- Decisions control conversion strategy
- Conversion strategy drives execution

No step operates independently.

---

## SYSTEM FLOW

1. **Analyst Agent (Doc 300)** → Collects data, scores opportunities, defines revenue signals
2. **Strategist Agent (Doc 304)** → Selects keyword, builds execution plan, converts revenue signals into CTA, offer, trust
3. **Manager / Synthesizer** → Validates alignment, approves or rejects

---

## STEP 1 — ANALYST AGENT (DOC 300)

### SCOPE (STRICT)

The Analyst Agent (Doc 300) performs **only keyword selection**. No SERP analysis. No Visby. No citation validation. Ownership passes to Strategist (Doc 304) after keywords delivered.

### CORE RESPONSIBILITY

Identify:
- Where revenue exists (leads/calls)
- Where conversion opportunities exist
- Which keywords support multi-brand presence

### REQUIRED OUTPUT (STRICT)

For each top keyword (limited to 2):

| Field | Output |
|-------|--------|
| **Keyword** | Exact keyword |
| **Assigned Pillar** | Pillar name that keyword strengthens |
| **Win Vector** | Why we can win - what competitors are missing - be specific |
| **Revenue Signal** | Correlation to actual leads/calls |
| **Brand Deployment Strategy** | Which brand(s) should target this and why (MasterShield → Premium tier, Klean Gutter → Mid-tier, MicroMeshGutterGuards.com → Manufacturer/parent) |
| **Selection Standard** | Revenue potential (H/M/L) \| Competitive gap (what we offer that others don't) \| Reason to win (specific advantage) |

### REJECT IF

- Pillar alignment weak or unclear
- Win Vector is vague
- Brand Deployment Strategy missing

### 🔒 FAILURE CONDITIONS

Reject output if:
- [ ] No pillar alignment
- [ ] No revenue signals
- [ ] No citation trigger
- [ ] No information gain

---

## STEP 2 — STRATEGIST AGENT (DOC 301)

### CORE RESPONSIBILITY

Convert:
- Revenue signals → conversion strategy → execution plan

### INPUT (FROM ANALYST)
- Pillar alignment
- Revenue signals
- Winning signals

### STEP 2.1 — KEYWORD SELECTION

Must prioritize:
1. Citation potential
2. Pillar alignment
3. Revenue potential
4. Then volume

If keyword does not strengthen a pillar → **REJECT**

### STEP 2.2 — REVENUE-DRIVEN CONVERSION STRATEGY

#### CTA STRATEGY
- CTA Type: **Soft / Medium / Hard**

#### OFFER STRATEGY

Select one:
- [ ] Guide
- [ ] Tool
- [ ] Calculator (Zero-Click Survival Tool)
- [ ] Diagnostic Tool (Zero-Click Survival Tool)
- [ ] Quote
- [ ] Estimate

#### TRUST STRATEGY
- Trust Level: **Low / Medium / High**
- Trust Type: **Proof / Authority / Mechanism / Local**

#### DECISION LOGIC (MANDATORY)

| If Revenue Signal | Then Use |
|-------------------|----------|
| Revenue Potential = High | Hard CTA + Direct Offer |
| Traffic High + Conversion Low | Soft CTA + Tool / Calculator |
| Conversion Gap = High | Increase Trust + Simplify Offer |
| Distribution Gap = Low | Focus on conversion, not traffic |

### STEP 2.3 — EXECUTION CORE

Must include:
- Search intent
- Information gain
- Citation structure
- Conversion path
- Internal linking

### REQUIRED STATEMENTS

1. **WIN STATEMENT:** "This page will win because: [clear reason]"

2. **REVENUE STATEMENT:** "This page uses a [CTA], [offer], and [trust level] because revenue signals indicate [reason]."

### 🔒 FAILURE CONDITIONS

Reject plan if:
- [ ] No revenue signal usage
- [ ] No pillar alignment
- [ ] No information gain
- [ ] No clear "why this wins"

---

## STEP 3 — MANAGER / SYNTHESIZER

### CORE RESPONSIBILITY

Final decision authority.

### YOU MUST VALIDATE

- Does this strengthen a pillar?
- Can this realistically win traffic or citations?
- Does this connect to revenue?

### FINAL DECISION
- **APPROVE**
- **REJECT**
- **PIVOT**

No "maybe"

### 🔒 FAILURE CONDITIONS

Reject if:
- No pillar alignment
- No revenue connection
- Weak conversion strategy
- No clear win condition

## SYSTEM RULES

**RULE 1:** Every keyword must strengthen a pillar.

**RULE 2:** Every decision must reference revenue signals.

**RULE 3:** Every page must include: Trust + Mechanism + CTA + Offer

**RULE 4:** At least one page per pillar must include Zero-Click Survival Tool
