 The Core Principle: Hierarchy is Absolute

> In any conflict, a document from a lower-numbered tier **always** overrides a document from a higher-numbered tier. There are no exceptions.

This is the single most important rule in the system. It prevents ambiguity and ensures that decisions are made consistently and predictably.

## 3.0 Conflict Resolution Protocol

When you identify a conflict between documents, follow this step-by-step protocol:

1.  **Identify the conflicting documents.**
2.  **Determine their tier** using the hierarchy above.
3.  **The lower-numbered tier wins.** (Tier 0 > Tier 1 > Tier 2 > Tier 3 > Tier 4).
4.  **If both documents are in the same tier, the document with the lower number wins.** (e.g., in Tier 0, Doc 224 overrides Doc 2236).
5.  **Log the conflict.** Add a note to the lower-precedence document flagging the conflict and stating which document overrides it.
