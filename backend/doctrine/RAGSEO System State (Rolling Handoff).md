## 7. Recurring lesson this whole engagement keeps re-teaching

A gate, a rule, or a skill that only works when someone remembers to invoke it isn't a gate, it's a courtesy. Every real gap found this session traces back to that one sentence: an audit that ran on request instead of always, a skill that updated in draft but not in the place that matters, a doc that claimed parity with another without anyone checking a real artifact. The fix, every time, has been to make the correct behavior the default that requires an active decision to skip, not the other way around. Apply that instinct to anything new before assuming it's fine.
