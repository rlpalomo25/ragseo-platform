## 1.0 The Weekly Goal

The system requires a steady input of high-value targets. The weekly goal is to select **exactly 5 keywords** for production.

**The "Work Until Done" Principle:** This target is a minimum. The team must work until 5 keywords are fully validated and approved, even if the analysis carries over into the next week. The pipeline cannot run empty.

---

## 1.1 Scoring Criteria & Thresholds

### Opportunity Score Formula

Each keyword receives an **Opportunity Score (0-100)** calculated as:

```
Opportunity Score = (Revenue Weight × 0.35) + (Search Volume × 0.25) + (Competition Gap × 0.20) + (AI Visibility × 0.20)
```

| Component | Weight | Calculation | Threshold |
|-----------|--------|-------------|-----------|
| **Revenue Weight** | 35% | Real lead/call data (CTM) / 100 | ≥ 15 |
| **Search Volume** | 25% | Monthly searches / 100 | ≥ 10 |
| **Competition Gap** | 20% | (100 - Domain Difficulty) | ≥ 30 |
| **AI Visibility** | 20% | AI Overview presence × 10 | ≥ 5 |

### Minimum Thresholds for Selection

| Metric | Minimum | Maximum |
|--------|---------|---------|
| **Opportunity Score** | 50 | 100 |
| **Monthly Search Volume** | 100 | 10,000 |
| **Domain Difficulty** | — | 70 |
| **Intent Match** | Problem/Solution | Commercial/Transactional |

### Priority Tiers

| Tier | Score Range | Action |
|------|-------------|--------|
| **Tier 1 (P0)** | 75-100 | Immediate production |
| **Tier 2 (P1)** | 50-74 | Queue for next cycle |
| **Tier 3 (P2)** | < 50 | Research only |

## 2.0 The Selection Process

This process begins after the Analyst Agent (Doc 300) has processed the raw data and generated the Opportunity Report.

### Step 1: Review the Opportunity Report
1. Open the weekly Opportunity Report generated by the Analyst Agent.
2. Sort the list by **Opportunity Score** (highest to lowest).
3. Filter out any keywords that belong to a Cluster or Local category if their parent Pillar page does not yet exist (per the 3-Phase Production Hierarchy).

### Step 2: The Human Sanity Check
For the top 10 keywords on the filtered list, perform a manual review using this checklist:

#### Sanity Check Checklist Template

**Copy this template for each keyword:**

```
KEYWORD: [Insert Keyword]
Date: [Date]
Reviewed By: [Name]

CHECKLIST:
☐ 1. Intent Match: [Problem/Solution/Commercial/Transactional]
    Notes: 
☐ 2. Cannibalization: [Yes - existing page / No - clear]
    Existing Page URL: 
☐ 3. Brand Fit: [MasterShield / Klean Gutter / MMGG]
    Reason: 
☐ 4. Stage Alignment: [TOFU / MOFU / BOFU]
    Page Type: [Pillar / Cluster / Local]
☐ 5. Seasonal Timing: [On / Off]
    Publish Month: 
☐ 6. Revenue Signal: [Leads: X] [Calls: X]
☐ 7. AI Visibility: [Question-based / Not]
    
RESULT: ☐ PASS (4+ checks including 1,2,3)  ☐ FAIL
```

#### Sanity Check Checklist (Reference Table)

| # | Check | Pass/Fail | Notes |
|---|-------|-----------|-------|
| 1 | **Intent Match:** Does keyword indicate a problem our product solves? | ☐ | Problem/Solution = pass; Commercial = evaluate |
| 2 | **Multi-Brand Check:** Search Doc 111 - is this keyword approved for multi-brand deployment? If YES (especially AEGIS 5X related), this is entity reinforcement - NOT cannibalization. Proceed if distinct angles exist per brand. | ☐ | Multi-brand = allowed; Single-brand = check existing coverage |
| 3 | **Brand Fit:** Which brand(s) should target? (MasterShield/Klean Gutter/MMGG) | ☐ | Per Doc 135 and Doc 300 multi-brand rules |
| 4 | **Stage Alignment:** TOFU/MOFU/BOFU matches page type? | ☐ | Pillar=TOFU, Cluster=MOFU, Local=BOFU |
| 5 | **Seasonal Timing:** Is this the right month to publish? | ☐ | Check Doc 191 |
| 6 | **Revenue Signal:** Does CTM data support this keyword? | ☐ | Real leads > 0 = pass |
| 7 | **AI Visibility Potential:** Can this rank in AI Overviews? | ☐ | Question-based = good |

**Decision:** Keywords must pass checks #1, #2, #3 AND have at least 4/7 total passes to proceed.

### Step 3: Select the Final 5
Select the top 5 keywords that pass the sanity check. 

**Important:** If a keyword is selected to be written for multiple brands (e.g., a MasterShield version and a Klean Gutter version), these count as **separate** targets toward the weekly goal of 5, because they require separate execution plans to avoid self-plagiarism.

---

## 3.0 The Approval Gate

Once the 5 keywords are selected, they must be formally approved before moving to Phase 3 (Data Collection).

1. Enter the 5 selected keywords into the **Keyword Selection & Approval Workflow (Doc 231)** tracker.
2. Assign the target Brand and Page Type (Pillar, Cluster, Local) for each.
3. The SEO Director reviews and signs off on the selection.

---

## 4.0 Handoff to Phase 3

Once approved, the 5 keywords are handed off to the **Strategist Agent (Doc 304)** for:
- SERP data collection
- Answer the Public questions
- Competitor benchmarks
- Execution Plan building

**Note:** The Analyst Agent (Doc 300) performs only keyword selection. It does NOT do SERP analysis, Visby, or citation validation. Those tasks belong to Doc 304.
