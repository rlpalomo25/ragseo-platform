# Doc 231: Keyword Selection & Approval Workflow

**Version:** 6.0 | **Last Updated:** April 3, 2026 | **Series:** 600 (Execution Guides)

---

## Purpose
This guide explains how the operator interacts with the Analyst Agent (Doc 300) and Strategist Agent (Doc 304) to select the weekly keyword and approve the Execution Plan. This is the critical operator-in-the-loop gate before content production begins.

---

## Step 1: Review the Opportunity Report
After you upload the weekly data (per Doc 151), the **Analyst Agent** will generate an Opportunity Report.

**What to look for:**
1. **Pillar-First Priority:** Are the top-scored keywords supporting our primary pillar (e.g., "gutter guards")?
2. **AI Overview Potential:** Did the agent flag keywords that currently trigger AI Overviews?
3. **Cannibalization Risk:** Did the agent flag any keywords that are too similar to what we already rank for?

**Your Action:**
- If the top recommendation makes sense, reply to the Analyst Agent: *"Approved. Proceed with [Keyword]."*
- If you want to pivot, reply: *"Skip [Keyword 1], let's target [Keyword 2] instead because [Reason]."*

---

## Step 2: Review the Execution Plan
Once the keyword is approved, the **Strategist Agent** will generate the full Execution Plan. This is the blueprint the Writer Agent will follow.

**The 5-Minute Checklist:**
Before approving the Execution Plan, verify the following:
- [ ] **Intent Stage:** Is it correctly labeled TOFU, MOFU, or BOFU?
- [ ] **Content Angle & Proprietary Data:** Did the Strategist specify an exact statistic or proprietary data point to guarantee Information Gain? (If it just says "use our data," reject it and ask for specifics).
- [ ] **CRO Placement:** Are the top 2-3 FAQs positioned *immediately following* the opening hook as a standalone decision unit?
- [ ] **Brand Assignment:** Is the correct brand module assigned (MasterShield, Klean Gutter, or MMGG)?
- [ ] **Visby Test Prompts:** Did the Strategist provide 1-2 test prompts for Visby.ai validation?

---

## Step 3: Visby.ai Validation (Optional but Recommended)
Take the test prompts generated by the Strategist Agent and run them through Visby.ai (see Doc 261 for the full Visby workflow).

- If Visby confirms our angle is missing from the current AI landscape, we have a green light.
- If Visby shows our angle is already saturated, ask the Strategist Agent to pivot the Content Angle.

---

## Step 4: Final Approval
Once the Execution Plan passes your review and Visby validation, give the final green light.

**Your Action:**
- Reply to the Strategist Agent: *"Execution Plan approved. Pass to the Architect Agent and Writer Agent."*

---
**End of Guide**
